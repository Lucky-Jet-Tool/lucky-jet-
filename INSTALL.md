# Install

## Folder structure

Place the five files inside a `docs` folder:

docs/
- lucky-jet-signals.md
- lucky-jet-bot.md
- lucky-jet-predictor.md
- how-it-works.md
- faq.md

## Repository README

Copy the contents of `README-REPOSITORY-SNIPPET.md` into the main repository README.

Relative links assume the `docs` folder is in the same repository as that README.

## Organization README

Copy the contents of `README-ORGANIZATION-SNIPPET.md` into `.github/profile/README.md`.

The organization snippet currently points to:
https://github.com/Lucky-Jet-Tool/.github/blob/main/docs/

So the docs should be stored in the `Lucky-Jet-Tool/.github` repository if you use that snippet unchanged.

If your main repository has a different name and you want the docs there instead,
replace `.github` in those five absolute URLs with the repository name.

## Suggested placement in both READMEs

Put the Documentation section:
- after the main explanation / features sections
- before the FAQ
- before the final CTA

This gives the README natural internal links without putting a link list above the main content.
