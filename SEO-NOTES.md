# Deployment / SEO Notes

1. Put `index.html`, `styles.css`, `script.js`, `robots.txt`, `sitemap.xml`, `.nojekyll` and `1.mp4`
   in the GitHub Pages publishing source.
2. Enable GitHub Pages in **Settings → Pages**.
3. Copy the final public Pages URL.
4. Replace every `YOUR_GITHUB_PAGES_URL` occurrence in:
   - `index.html`
   - `robots.txt`
   - `sitemap.xml`
5. Commit and push again.
6. Add the final Pages URL to the repository **Website** field.
7. Use Google Search Console URL Inspection to request indexing and submit `sitemap.xml`.
